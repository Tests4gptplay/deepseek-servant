## 原生运行与清理

运行顺序为：启动后台任务、运行中强制重置、执行清理、完成新的 Local 任务、完成新的 Git 任务。

| 项目 | 观察结果 |
| --- | --- |
| 运行中重置 | Worker 的原生后台作业被标记为 `killed`；Agent 与 Session 释放，活动 Job 和待处理输入归零 |
| 中断后续作 | 任务保持取消，未重新派发；已有产物保留，取消后预定生成的文件未产生 |
| 完整历史清理 | 已结束测试任务的历史和索引删除；遗留的 10 个任务身份标记与 9 份交付回执一并清除，实测回收 19,181 字节 |
| 文件用量 | 清理后记录目录为 1,766 字节，接口统计与实际文件大小一致；档案、原始需求、聊天、规划记录及临时记录均为 0 |
| 配置保留 | 剩余文件为助理设置、运行设置和目录布局标记 |
| 非空规划记录清理 | 两份测试文档清空，后续统计为 0 |
| Local 完整任务 | Planner 派发、Worker 创建并读回成果、Planner 验收及前台交付完成；成果再次读回匹配预期 |
| Git 完整任务 | 经模式路由提交，Worker 创建并读回成果，Planner 独立验收根目标，前台完成交付；任务状态为 `accepted`，成果再次读回匹配预期 |
| 模式隔离 | Local 空对话未混入 Git 历史；Git 投影仅显示 Git 消息。客户端回归确认切换时清空跨模式分页缓存 |

原生紧急停止以 `aborted` 收尾。Git 执行中对尚未创建的记录、初始修订号及目标目录进行了纠正，随后完成任务与交付。
