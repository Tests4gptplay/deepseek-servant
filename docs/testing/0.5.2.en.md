Cold recovery and same-workline capacity transfer passed, including two admitted worklines, exclusion of a third, prior execution identity, and cleanup boundaries. |
| Task creation order | Local and controlled Git tests verified that creation time is set at first admission, retained after reopening, and not invented for older records. This was not a desktop UI test. |
