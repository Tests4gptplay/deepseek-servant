# 候选9变更依据

## 本次更新

- Git任务页显示实际执行进度与成果；新计划或结果尚在发布时显示更新中，避免误读为空。
- Git输出改为流式接收，移除原64MiB缓冲拒绝；已有[真实65MiB Git对象完整性用例](../../tests/git-runner.test.ts)，不据此宣称整体速度提升。
- 修复多处程序错误，改善运行稳定性。

平台证据：Linux真实DSH完成Local10、Git10与五专项；Windows路径/启动参数有组件回归，Windows/macOS按实机要求验证。现有Git多事务机制不变；共享conversation自动消费和框架重设计不是本次完成的新功能。

[具体用例步骤、预期、实际结果与净化证据](EVIDENCE.md)

- **Git执行与成果投影**：早期实际宿主记录存在执行/成果，而任务视图未映射对应字段。投影使用已有角色记录呈现进度和成果；执行协议不变。
- **重复结果幂等性**：同一结果经storage序列化后键顺序不同，旧比较误报RESULT_ID_REUSED。回归覆盖语义相同的重复结果与真正不同内容；实际Local重复结果专项通过。
- **故障与storage恢复**：实际故障诊断揭示关闭owner/待收尾动作及恢复状态的问题；候选修正对应生命周期，源码回归和实际Local五专项核对最终owner/错误收尾。
- **候选9更新中提示**：候选8实际Git推进期间，尚未发布的新计划/结果投影短暂显示“No accepted results yet”。候选9仅增加可选只读投影状态及短提示“计划更新中/结果更新中”；已确认参与者的结果继续显示。未新增缓存、轮询、同步门禁或调度机制。真实Light/Dark及发布后的恢复均观察通过。
- **介绍澄清**：说明Local持续任务和实验性Git协作的实际入口、角色分工、远程输入与共享聊天消费区别。纯文案包只改变README、PRIVATE_GIT、USAGE及package简介；运行代码和美术资源保持验收字节。

本分支保留现有Git多事务结构，未混入后续框架重设计。源码、安装包和[验收范围](ACCEPTANCE.md)应一起查看。
