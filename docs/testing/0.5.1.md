# DSS 0.5.0／0.5.1 对比测试

[首页](../../README.md) · [0.5.1 更新说明](../releases/0.5.1.md)

## 测试任务

一次从 DSS 前台提交供需审计和独立质检。两套 DSH 协作：一端汇总订单和质检报告，另一端核算库存，再汇总缺口。任务要求保留结果、独立验算并归档。两版各完成四个任务，最终两份报告逐字一致。

| 测试输入 | 预期结果 |
|---|---|
| 三张订单：A×3/B×2、A×4/C×1、B×5/C×2 | A 要 7 件，B 要 7 件，C 要 3 件，共 17 件 |
| 可用库存：A 7 件、B 3 件、C 2 件 | 缺口 A 0 件、B 4 件、C 1 件 |
| 质检 38 件，发现 3 件不合格 | 合格 35 件 |

## 测试环境

- ChatGPT Dot 后台负责操作与记录。使用云端 Linux（x86-64），两套 DSH **0.2.2-rc.3**，Node.js **24.22.1**。从 DSS 前台键盘输入、鼠标点击发送。
- 在同一个隔离的 Git HTTP 测试环境串行运行，采用相同输入、固定测试模型、标准预设，每任务两个 Worker 席位。两版各测一轮。Git HTTP 计数来自隔离仓库，不含公网 GitHub 延迟。
- **0.5.0 基线**使用 RC5 实测包；正式 0.5.0 另包含 Windows 启动兼容性更新。**0.5.1**使用转正前的验收包实测，正式包沿用相同的 Host 和界面。

## 测量结果

耗时从 DSH 收到前台提交起算。Git 请求从同一起点计到对应阶段；推送被拒是 Git 请求结果，任务结果另计。

| 测量项 | 0.5.0（RC5 基线） | 0.5.1 | 变化 |
|---|---:|---:|---:|
| 最终回复确认写入 | 117.031 秒 | 107.309 秒 | 少 9.722 秒 |
| 两份归档全部写入 | 110.689 秒 | 97.050 秒 | 少 13.639 秒 |
| 两端任务全部释放 | 128.316 秒 | 113.143 秒 | 少 15.173 秒 |
| 至最终回复的 Git HTTP 请求 | 12,620 | 11,128 | −11.8% |
| 其中读请求 | 10,511 | 9,329 | −11.2% |
| 至最终回复的推送被拒次数 | 271 | 224 | −17.3% |
| 至全部释放的 Git HTTP 请求 | 13,463 | 11,488 | −14.7% |
| 固定测试模型请求 | 132 | 132 | 持平 |

在这组任务中，0.5.1 以相同的模型请求数交付了相同的结果，Git 请求减少。以上是本场景单轮观测。

0.5.1 另用前台验证了 Local／Git 的短任务、独立任务、并发任务，以及 Local 记录目录迁出、迁回和取消搬迁。
