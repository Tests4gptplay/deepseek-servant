# 《鲸骨以北》本机试玩

[下载冻结版试玩包（ZIP，3.38 MB）](https://raw.githubusercontent.com/Tests4gptplay/deepseek-servant/refs/heads/test/0.5.2/docs/testing/0.5.2/work-long-run/demo/whalebone-north-demo-dc4d9d4f.zip)

## 启动

1. 解压整个压缩包。在包含 `start.mjs` 的目录打开终端。
2. 确认已安装 Node.js 18 或更新版本，运行 `node start.mjs`。不需要安装 npm 依赖。
3. 用浏览器打开终端显示的完整本机地址。结束后，在终端按 Ctrl+C。

## 操作

- 方向键或 WASD 移动，E 与人物、物品或出口互动。用鼠标选择对白与行动；触屏可用画面上的按钮。
- 开局从玛拉身边的抬棺人塔婶开始。右上角可切换声音或查看航海志，右下角可存档。
- 存档留在当前浏览器和端口。更换设备前可从存档菜单导出 JSON。默认端口被占用时，可运行 `node start.mjs 43873`。
