## 观察口径，不作为前台路由指令
- 两席指两条活跃工作线，不按在线 Worker 数计；同线换代承接席位，确认没有正在做或待接续的工作才释放。旧会话在线或缺停止回执不是占席依据。
- 如实际运行出现 Planner，观察止轮是否有有效业务动作：未完有明确后继且真实交接，完成有正式结项，确需用户才交前台；不能把“下轮继续”或原生止轮当成有效交接。
- 如触发 Helper，须以正确工作线的新成果或有效交接验证恢复，分别记录自主恢复、Host 兜底、Dot 恢复和未知；不把回执当产出，不为构造场景改 Organizer 规则。
