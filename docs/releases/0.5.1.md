# DeepSeek Servant 0.5.1

本次更新集中优化任务响应、Git 协作、连接状态显示和设置操作。

- **任务推进更顺畅**：对消息处理、后台协作、成果归档与收尾做了多项优化，减少重复等待。
- **Git 协作更轻量**：减少协作任务中的重复访问与推送冲突，改善并发任务的处理效率。
- **连接状态显示修复**：恢复已连接状态的绿色指示，便于识别当前状态。
- **设置与记录搬迁**：改善文件夹选择和记录目录显示，支持将记录迁回原目录并保留原有记录；搬迁失败后可在当前页面直接重试或放弃，无需手动刷新。

在 DSH 打开 **插件 → 添加插件**，输入：

```text
github:Tests4gptplay/deepseek-servant#v0.5.1
```

[安装与升级指南](https://github.com/Tests4gptplay/deepseek-servant/blob/v0.5.1/docs/INSTALLATION.md)

## English

This release improves task responsiveness, Git collaboration, connection status, and settings.

- **Smoother task progress:** Reduced waiting across message handling, background work, archiving, and cleanup.
- **Lighter Git collaboration:** Reduced repeated Git requests and push conflicts during collaborative work.
- **Connection indicator fix:** Restored the green indicator for an active connection.
- **Settings and record relocation:** Improved folder selection and the display of the active records folder. Records can be moved back to their original location while preserving the earlier copy. Failed moves can be retried or abandoned from the same page without refreshing.
