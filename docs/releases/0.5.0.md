# DeepSeek Servant 0.5.0 历史候选说明

本文保留原 v44 所附候选包的发布与验证记录，描述的是 Local 物理存储改造之前的对应源码和安装包。下文的 SQLite、清理流程、包名及测试结果只属于当时的候选，不代表当前源码行为或当前安装包；历史测试事实未据后续改造改写。当前功能与安装入口请查阅 [README](../../README.md) 和 [安装说明](../INSTALLATION.md)。

## 安装本次联合测试包

本源码快照使用单个 `deepseek-servant-0.5.0-memory-git-local-candidate.tgz` 安装包，内含 DSS 与独立原生会话 Cleaner。包内版本仍显示 **0.5.0**；以交付清单中的包名与 **SHA-256** 区分本次候选，不以版本号或旧 RC2 标签区分。

下载交付的 TGZ 后，在运行 DSH 的电脑上保留该文件。在 **插件 → 添加插件 → 包名或地址** 中填写其完整绝对路径，无需解压。安装后启用插件，按宿主提示重启。**旧 `v0.5.0-rc.2` 标签与下载地址不包含本次改动，请勿用于本次测试。** 本候选没有新的公开标签、市场链接或 Release。

**升级与资料保留：** 先正常停止 DSS 执行并保留原数据备份；建议先在独立测试 profile 验证。若宿主提示已安装，先卸载插件条目，再从本次 TGZ 安装。保留 DSH 数据目录、Local 库及任务工作区，不手工删除记录或数据。Desktop 需要时完整退出托盘进程后再打开；升级后检查设置、对话、任务记录与成果可读取。

**Web：** 先停止对应 profile，在运行该服务的环境执行，之后重启：

```sh
dsh plugin --profile web add '/absolute/path/deepseek-servant-0.5.0-memory-git-local-candidate.tgz'
```

将示例替换为交付包在运行 DSH 的电脑上的实际绝对路径。Desktop 与 Web 分别管理安装。模型提供者与工具权限仍由 DSH 管理。测试证据与平台边界见随包交付清单；尚未执行的 Windows 实机与真实界面验收不应视为已通过。

## Local / Git 统一协作

Foreground、Organizer、Planner、Worker、Recorder、Helper 使用 DSH 原生 Agent、Session、工具与 Jobs。Local 使用 SQLite 文件库，Git 在私有协作仓库使用远端树和 blob；任务、原子提交、角色交接与恢复采用统一接口。前台访问与本端后台参与分别管理。

## 前台与历史

- Foreground 每轮完成后使用新原生会话接续，带入最近六个完整往返原文；普通可见最终回复保存在共享对话中，并核对同轮显式发送以避免重复。
- 历史支持连续上滚和日期定位。Local 选日从当日末尾开始、限定当日；Git 选日先定位该日末尾，后续游标可跨日。
- AI 可按需全文搜索和按字符分页读取长文；保存的原文保持完整。工作清单与缓存的用途、路径及操作指南自动提供，正文按需读取。
- 已迁移的旧任务提供完整原记录入口；Local 可导出实际保存的全文。知识页展示项目事实、偏好正文及范围/来源，技能另有候选与停用操作。

## Local 记录管理

三类操作分别确认：**清理任务历史**、**清理前台对话**、**清理工作规划记录**。任务历史清理保留成果与其他任务引用的资料。取消 Task 只有在持久取消意图和精确生产者停止证据均成立后才可清理；状态保持原事实，不写成 complete。明确清理回执阻止旧 Task 重新执行或接受补充，后续业务使用新 Task。

**搬家并应用**先保存原操作、确认本插件拥有的执行停止，再复制核验技术记录和 Local 库并切换设置。原 scope、任务、命令、会话与消息身份保持；响应未知时核对原请求，重启后可继续核对。宿主原生日志不在此搬迁范围。

## 成果保全

Recorder 按职责编写长期记录；Cleaner 接到信号后按固定范围清理任务运行资料，不读取或核验长期归档、技能及成果，不承接或等待技能刷新，也不回交 Recorder。成果附件按真实字节保存、核验和下载，任务间引用继续保留。清理回执关闭旧运行命名空间，前台长期规划、技能及诊断各按自身职责使用。

## 验证范围

验证范围包括源码回归、真实 SQLite、官方原生服务组合、受控模型/HTTP 和 React 组件。跨不同真实账户的公网联合协作尚未执行。各项结果随对应 Release 记录。
