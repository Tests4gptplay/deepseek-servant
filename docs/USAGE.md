# DeepSeek Servant 使用指南

对应版本：`0.3.1`。安装入口见[安装指南](INSTALLATION.md)。“对话 / 任务”旁的菜单显示 `local` 或 `DSS-cah`，切换后仍在原对话框讨论目标，前台按要求投递任务；既有后台任务继续运行。协作连接、外部投递与 Git 记录见[协作指南](../PRIVATE_GIT.md)。

以下为 Local 模式使用方法。

## 1. 选择模型与工作区

1. 从 DSH 左侧导航进入 DeepSeek Servant。
2. 在输入框底部选择前台模型与思考强度。
3. 在设置中选择工作区，或为 Servant 指定独立文件夹。
4. 后台模型默认 `Auto`，跟随本页前台模型及思考强度，也可单独指定。

设置只属于当前 Servant 助理，DSH 普通会话保持各自配置。已提交任务继续采用创建时的工作区、模型和 preset；模型、preset 或工作区切换在前台空闲边界生效。

## 2. 交代任务并持续交流

直接在对话中说明目标、需要保留的内容、交付物和验收要求。Foreground 通过持久 Task 提交执行需求，Planner 制定有界计划，Worker 实际执行。后台工作期间可以继续与前台交流。

补充或修正同一项工作的要求时，直接说明是哪项任务及变更，前台将它记入原 Task。已接受成果继续保留，Planner 调整受影响部分。

后台需要具体信息时，会显示问题和恢复条件。可以在任务详情回答，也可以直接在聊天中答复；前台将实际用户原文转交对应等待并接续任务。

任务验收完成后，前台主动给出结果与实际文件链接，侧栏显示原生完成标记。任务详情保留目标、结果、记录导出与已读状态。

## 3. 并发、暂停与取消

- **Worker 席位**：设置页可保存正整数，默认 2。调高后应用于后续调度；调低后已有 Worker 自然到达当前完成或交接边界。
- **优先级**：较大的整数优先派发，当前执行继续运行。
- **暂停**：暂停后续业务推进，详情继续显示在途执行和作业。
- **继续**：从已保存进度恢复调度。
- **停止执行**：针对详情中的确切执行请求停止。
- **取消任务**：结束该目标的后续推进，保留已有成果和记录。

上述操作可使用任务详情入口，也可以在当前对话明确提出。

## 4. 阅读长对话

向上滚动会提前加载更早原文，并保持当前阅读位置。日期筛选使用跟随 DSH 主题的日历，支持键盘选择；“全部日期”恢复完整历史。

每次完成用户交互后，下一物理 Session 自动带入最近六次完整用户/助理往返；更早原文仍可检索和补读。后台完成通知单独保存。

“工作规划记录 / Work Planning Notes”包含 Foreground_List 重要交代索引与 Foreground_Cache 随记，两者默认保留，支持整理和更新，无字数上限；仅按用户要求删除或清空。前台交流时按 7 天提醒、30 天确认的节奏询问搁置事项，按答复更新状态与复查时间。任务完成、话题结束或内容陈旧不自动删除记录。两者只自动告知用途和读取入口，正文按需阅读。

## 5. 重启后的接续

宿主重启、异常退出或断电后，再次启动 DSH，Servant 读取保存的任务、角色和原生执行事实。失活运行由原角色接续，保留已完成文件、工作前沿和任务身份；前台继续未完成的原消息。暂停、取消和仍存活的实际执行归属照常保留。

正常长作业由持有它的原 Worker 等待并收取结果。缺少具体配置或用户信息时，按详情显示的问题补齐即可继续。

## 6. 记录与界面设置

- “Servant 记录管理”展示六项长期记录、六项临时记录及合计；可迁移记录存储位置。
- 已结束任务可导出完整 records 为 Markdown；临时状态自动在封存与交付后清理。
- “清理前台对话”单独处理前台原文，工作规划记录、后台 Task、知识和待交付结果保留。
- 历史任务索引计入“已完成任务档案”；腾出的长期统计行显示“工作规划记录”，左右仍各六项。
- “清理工作规划记录”单独清空当前助理的 List 与 Cache，聊天和技能保留；相对所选存储位置，实际记录归入 `deepseek_servant/work-planning/`，完整档案及历史索引归入 `deepseek_servant/archives/`。
- “清理已结束任务”收起历史入口并释放相应临时状态，完整 records 继续可读。
- 页面插画可在“实验性 → 页面插画”开关右下角人物或互换两页素材；助理名称和用户名称在设置中保存。

详细存储与清理规则见[记录、归档与清理](../RETENTION.md)。Private Git 实验模式见[协作指南](../PRIVATE_GIT.md)。
